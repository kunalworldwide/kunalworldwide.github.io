A hands-on workshop built on one premise: you don't learn agents by watching slides, you learn by shipping one.

120 developers showed up with laptops at OJone, Marathahalli as part of Bengaluru Tech Week 2026. The format was simple. A short tour of how agents actually work under the hood: the reasoning loop, tool use, and when an agent beats a plain LLM call. Then everyone built one on Kimchi.dev with multi-model routing, /ferment workflows, and spend guardrails baked in.

The second half was a challenge: build a working web app and deploy it live to Vercel or GitHub Pages before lunch. 9 projects shipped, including an AI SOC for security alert reduction, a GitHub repo to architecture diagrams tool, and a brain training app.

Key topics covered:

- What an AI agent actually is: LLM brain, tools, and the reasoning loop
- Agent vs chatbot: when autonomy pays for itself and when it doesn't
- Multi-model orchestration: orchestrator, builder, and reviewer roles routing work to the right model
- /ferment: multi-session projects with milestones and self-evaluation
- Tool use and governance: permissions, spend caps, and cost attribution
- Shipping live: deploying to Vercel or GitHub Pages in under 60 seconds
